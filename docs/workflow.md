# Workflow

## Flujo de trabajo

### 1. Buscar posibles clientes
Fuentes:
- Google Maps
- búsquedas locales en Google
- Instagram
- directorios locales
- recomendaciones / boca a boca

### 2. Hacer cribado rápido
Evaluar en 5-10 minutos:
- ¿tienen web?
- ¿la web está desactualizada?
- ¿carga bien en móvil?
- ¿hay CTA claro?
- ¿transmite confianza?
- ¿el negocio parece activo?
- ¿se puede mejorar mucho con poco esfuerzo?

### 3. Puntuar oportunidad
Usar una puntuación simple del 1 al 5 en cada eje:
- necesidad de mejora
- potencial visual
- capacidad comercial percibida
- facilidad de ejecución
- interés estratégico

### 4. Crear ficha del lead
Guardar:
- nombre del negocio
- ciudad
- URL web
- Instagram
- teléfono / email si aparece
- observaciones
- puntos débiles detectados
- ideas rápidas de mejora

### 5. Preparar enfoque
Elegir una de estas opciones:
- mensaje en frío breve
- auditoría corta en PDF / markdown
- demo visual rápida
- propuesta de rediseño con roadmap

### 6. Si hay interés
Abrir trabajo real:
- definir alcance
- presupuesto
- tiempos
- stack
- assets necesarios
- contenidos pendientes

## Regla práctica

No invertir horas en demos completas para leads flojos.
Primero detectar potencial real y luego profundizar.

## Señales de prioridad alta

- negocio bueno con imagen mala,
- sector donde el diseño vende,
- competencia local claramente mejor posicionada,
- web rota / vieja / lentísima,
- identidad visual aprovechable,
- ticket medio suficiente.

## Señales de prioridad baja

- negocio inactivo,
- web aceptable y difícil de mejorar comercialmente,
- cliente muy sensible a precio,
- poca presencia digital general,
- sector sin retorno claro.
