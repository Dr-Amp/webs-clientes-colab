# Visión

Este repo no es solo para guardar webs.

Es el workspace compartido entre Roberto y su colega programador para montar un sistema de captación, propuesta, producción y entrega de webs para negocios locales.

## Objetivo principal

Crear un sistema simple para:
1. detectar negocios con mala presencia web,
2. valorarlos como posibles clientes,
3. preparar una propuesta clara,
4. construir una demo rápida,
5. convertirla en proyecto real si el cliente entra.

## Qué debe entender un colaborador al entrar

- Qué tipo de clientes buscamos.
- Cómo se detectan.
- Cómo se priorizan.
- Qué materiales se preparan antes de contactar.
- Cómo se pasa de idea a demo y de demo a proyecto.

## Perfil de cliente ideal

Negocios locales con una o varias de estas señales:
- web antigua o inexistente,
- diseño poco profesional,
- sin adaptación móvil,
- SEO local flojo,
- ficha de Google poco trabajada,
- Instagram activo pero web mala o nula,
- negocio visual donde una buena landing puede vender mucho mejor.

## Tipos de negocio prioritarios

- gimnasios
- clínicas / veterinarios
- floristerías
- estética / peluquería
- restaurantes / cafeterías
- profesionales locales con servicios premium

## Entregable mínimo útil

Antes de hablar con el cliente, idealmente tener:
- mini auditoría,
- propuesta de mejora,
- una demo o referencia visual,
- estimación de alcance,
- siguiente paso claro.
