# Cliente ideal

## Qué estamos buscando

Negocios locales donde una mejor web pueda generar:
- más confianza,
- más contactos,
- más reservas o pedidos,
- mejor imagen de marca.

## Buen cliente potencial

- negocio activo
- servicio claro
- margen decente
- presencia visual aprovechable
- competencia que ya se está moviendo mejor
- propietario con interés comercial mínimo

## Mal cliente potencial

- negocio abandonado
- inversión cero
- necesidad poco clara
- servicio mal definido
- sin activos ni voluntad de colaborar

## Sectores interesantes

- salud animal / veterinaria
- fitness
- floristería
- estética
- restauración
- bodas / eventos
- comercios especializados

## Qué mirar rápido

- home desactualizada
- textos pobres
- fotos malas
- ausencia de llamadas a la acción
- mala experiencia móvil
- branding inconsistente
- Google Maps / reseñas desaprovechadas
